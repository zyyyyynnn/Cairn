## 1. 产品定位与核心目标

### 1.1 产品定义
**Cairn** 是一款面向 Windows 10 (1809+) 与 Windows 11 (x64) 的开源（`Apache-2.0`）、中英双语、高性能本地文件即时检索与安全管理桌面工具。
- **底层内核**：直接流式读取 NTFS 卷主文件表（`$MFT`）建立紧凑常驻内存索引，通过 USN 变更日志（USN Change Journal）保持近实时增量追赶，并提供进程隔离的可选 Tantivy 全文检索支持。
- **桌面表现**：基于 Rust + GPUI Kit（`gpui-kit`）构建高密度现代化桌面界面，融合现代化文件管理器（Windows 11 Explorer / Files App）的结构化导航与 Everything 的毫秒级即时检索体验，原生提供严格灰阶语义令牌、无损中文输入法（IME）适配与完备的键盘快捷流转。
- **单向解耦**：内核引擎、后台服务与界面交互严格单向分层解耦，服务坚守只读安全边界，桌面端可通过标准接口独立演进或替换。

### 1.2 目标用户与使用场景
- **目标用户**：中文环境下的开发者、系统运维工程师与重度文件管理用户，单机文件规模通常在数十万至数千万级别。
- **典型场景**：
  1. 通过模糊子串、复合逻辑（`AND`/`OR`/`NOT`）或正则表达式，在数千万文件量级下瞬时（≤ 30ms）定位项目代码、工程构件或文档；
  2. 依赖 `size:`、`dm:`/`dc:` 等时间与大小谓词快速排查大文件或近期变更；
  3. 基于 `content:` 语法在指定代码仓或文档目录下精准检索含特定文本或标识符的文件内容；
  4. 纯键盘无鼠标流转完成打开、所在目录资源管理器定位、路径复制、安全重命名与安全移入回收站。

### 1.3 核心设计目标
1. **速度与资源标杆**：文件名搜索中位延迟与常驻内存基准全面对标并力争超越 Everything 1.4。
2. **零静默过期原则**：文件系统变更近实时反映至搜索结果；当卷处于任何非同步状态时，协议与界面必须显式标注，**严禁在非同步状态下静默返回过期数据**。
3. **中文输入法原生态体验**：彻底根治 GPUI/Zed 在 Windows 下中文输入法组合丢字、重复上屏、候选窗错位及遮挡问题。
4. **服务只读与操作安全**：后台特权服务坚守 100% 只读红线，杜绝提权写漏洞；写操作由免提权客户端直接调用系统原生 Win32 `IFileOperation` 安全执行。
5. **可验证性与门禁闭环**：所有性能指标、内存预算与一致性结论均有端到端自动化测试脚本和集成测试夹具支撑。

### 1.4 北极星成功指标（North Star Metrics）

| 编号 | 核心维度 | 对标基准与量化验收标准 |
|:---|:---|:---|
| **SM-1** | **文件名搜索速度** | 同机、同语料、同查询集（≥10 条典型查询，均按名称排序取完整结果集，预热 2 次取 6 次中位数）对比 Everything 1.4，查询中位延迟不劣于 Everything；400 万条下常见查询首屏 **P95 ≤ 30ms** |
| **SM-2** | **常驻内存占用** | 400 万条索引下，`cairnd` 服务常驻内存不高于 Everything 1.4（基础索引 **≤ 125 字节 / 条**，400 万条约 500MB；每个预排序索引 **4 字节 / 条**）；GUI 空闲内存 **≤ 150MB** |
| **SM-3** | **中文输入法兼容性** | 在微软拼音、搜狗拼音、微信输入法 3 款主流输入法下，搜索框组合输入零丢字、零重复上屏，候选窗精确跟随光标且不遮挡输入行（完整通过 [engineering/quality.md](engineering/quality.md) 专项测试清单） |
| **SM-4** | **增量同步实时性** | 文件创建、重命名、删除、移动后可被搜索到的端到端延迟 **P95 ≤ 1.5 秒**；已索引文件内容修改后 **≤ 10 秒** 可被全文检索命中 |
| **SM-5** | **索引状态与一致性** | 1 万组随机文件操作序列下，USN 增量更新索引与 `$MFT` 全量重建结果 **零差异**；卷处于非同步状态时必须显式标注，**严禁在非同步状态下静默返回过期数据** |

## 2. 范围、优先级与能力基准

### 2.1 系统约束
- **运行平台**：Windows 10 (1809+, OS Build 17763+) 及 Windows 11，仅支持 x64 架构。
- **开发与构建环境**：Rust Stable（严格锁定于根目录 `rust-toolchain.toml`），Windows 11 + PowerShell 7+，UTF-8 字符集。
- **架构模式**：后台 Windows 服务固定以 `LocalSystem` 运行（读取裸盘 `$MFT`/USN、维护受保护索引） + 免提权桌面 GUI 客户端，通过本地 Win32 命名管道进行 IPC 通信。**安装完成后由 SCM 自动启动服务；日常双击 `cairn.exe` 无需管理员权限，也不会弹 UAC。** 服务不可达时 GUI 先尝试一次免 UAC 的 SCM 静默启动；仍不可用时以当前用户身份启动内置的本地索引器（`cairnd --user-mode`，独立管道 `\\.\pipe\Cairn.User`），窗口照常显示“所有文件”表格，只是可索引范围限于该账户可读的目录。运行期唯一可能提权的动作是服务问题带在服务已安装但未运行时提供的显式启动恢复入口。
- **界面语言**：简体中文（`zh-CN`）与美式英文（`en-US`），默认跟随操作系统的语言设置并支持界面手动切换。
- **开源许可**：全工作区遵循 `Apache-2.0` 开源许可证。

### 2.2 优先级划分（Milestones）

| 优先级 | 范围与包含特性 |
|:---|:---|
| **P0 (核心基础)** | 本地固定 NTFS 卷 `$MFT` 流式索引、USN 增量同步与故障重建、Everything 核心语法（与或非/引号/通配符/大小写/全字/匹配路径/正则）、四段式现代高密度灰阶 GUI、后台 Windows 服务（`cairnd`）、中英双语（`fluent-bundle`）、中文输入法（IME）四大缺陷根治、纯文本内容检索 |
| **P1 (完善增强)** | 富文档（`docx`/`xlsx`/`pptx`/`pdf`）抽取与 Worker 进程隔离、命中片段切片高亮渲染、快速过滤器内置宏、系统托盘与全局热键唤起、免提权 CLI 查询工具（`cairn-cli`）、WiX Burn 单文件安装包（`CairnSetup.exe`）工程与构建溯源 |
| **P2 (生态演进)** | Everything IPC / `es.exe` 兼容适配层、FAT32 / exFAT 卷轮询扫描、ReFS 卷支持、中文拼音与首字母搜索（`py:`）、Windows 系统 IFilter 原生接入、系统级文件预览窗格、ARM64 架构构建支持 |

### 2.3 边界与非目标（Non-Goals）
1. **服务只读红线**：后台提权服务绝对不提供任何修改文件系统（写入、重命名、删除、移动）的管道接口，防止特权服务沦为写操作攻击面。
2. **免提权客户端安全操作**：仅允许在免提权 GUI 进程中，通过 Windows 原生 Win32 `IFileOperation` / `SHEmptyRecycleBin` API 规范触发删除到系统回收站、从回收站还原、永久删除与清空回收站，由 Windows Shell 原生承载进度与错误；日常删除与永久删除使用项目统一确认框，清空回收站保留 Windows 原生警告。`F2` 重命名尚未实现。严禁向后台服务暴露写管道。
3. **平台与介质边界**：首版聚焦本机固定 NTFS 卷，不包含 macOS、Linux、云盘同步盘、网络共享（SMB/ETP）、远程查询管道。
4. **功能边界**：不引入语义 / AI 向量搜索、OCR 图片文字识别、远程遥测上报、用户账号体系或动态外部插件系统。

### 2.4 能力判据体系（Criteria）
1. **三档打通判据**：一项能力必须在**语法（core 解析器识别）**、**执行（service/engine 实际过滤）**与**界面可达（GUI/CLI 具备入口且反馈）**三档全部打通，才判定为“已具备”。代码存在但无调用入口的标记为“待接线”。
2. **一手出处判据**：所有对标能力必须具备官方支持文档或作者发布公告等一手证据，严格区分 Everything 1.4 已有与 1.5 新增特性。
3. **排除项边界**：明确不采纳 Everything 网络供数面（ETP/HTTP Server/SDK 外部供数）、遍历型工具特征（gitignore 规则、目录深度限制 `fd -d`）以及终端 TUI 范式（分屏、终端颜色）。

## 3. 九域能力基准与现状清点

基于 [research/references.md](research/references.md) 所列一手调研文献，系统梳理同类产品能力矩阵及 Cairn 当前代码的实际闭环状态：

### 3.1 检索模型（Search Model）
- **同类基线**：子串匹配、正则表达式、通配符（`*`/`**`/`?`）、大小写控制、路径匹配开关是桌面与 CLI 检索工具（Everything、fd、ripgrep、fzf）的通用基线。
- **差异化能力**：Everything 1.5 引入的标点忽略（`ignore-punctuation:`）、空白忽略（`ignore-whitespace:`）、前后缀词边界（`prefix:`/`suffix:`）及变音符号控制（`diacritics:`）。
- **Cairn 闭环现状**：
  - `case:`、`ww:`、`path:`、`regex:`、通配符、逻辑组合（`!`、`|`、`<...>`、`"..."`）三档全通（达标）。
  - `prefix:` 与 `suffix:` 词边界匹配已在 `cairn-core/src/engine.rs` 完整实现（达标）。
  - 日期函数 `dm:`/`dc:` 全面支持相对时长（`2days`）、ISO 日期、`YYMMDD`、月份星期名常量及 `mtd/ytd/qtd`（达标）。
  - 正则查询已接入缓存机制，避免逐行重新编译导致性能退化（达标）。

### 3.2 列与元数据（Columns & Metadata）
- **同类基线**：Everything、Files App 与 eza 均支持多列长格式展示，名称、路径、大小、修改时间为核心基准列。
- **差异化能力**：列宽自适应记忆、表头右键动态显隐扩展列（创建时间、扩展名）、内容派生元数据（代码行数、音频标签）。
- **Cairn 闭环现状**：
  - 虚拟表格稳定渲染名称、路径、大小、修改时间四列，列宽比例与数值对齐符合规范（达标）。
  - 排序列与排序方向已接入 `%APPDATA%\Cairn\settings.toml` 读写（达标）；四列宽度可拖动表头分隔线调整，并在释放时回写同一配置、下次启动恢复（达标）。
  - 文件名与路径命中区间切片高亮：`query_orchestration.rs` 切片、`results_view.rs` 渲染（达标）。
  - 系统真实原生小图标缓存已在 `icon_cache.rs` 准备就绪，当前表格使用极简单色矢量图标以保障高密度性能（接线项）。

### 3.3 导航结构（Navigation Structure）
- **同类基线**：Files App 采用 `Omnibar` 整合面包屑与搜索；现代文件管理器普遍配备可折叠导航侧栏。
- **Cairn 闭环现状**：
  - 侧边栏支持由按钮收起/展开（达标）；收起/展开的快捷键尚未绑定（待接线）。
  - 侧栏类型过滤（8 大分类）与卷作用域切换完全打通（达标）。
  - 主搜索框全宽延伸，直连数据表头（达标）。

### 3.4 筛选与分面（Filters & Facets）
- **同类基线**：类型宏、扩展名集合筛选、按文件大小与日期区间分面过滤。
- **Cairn 闭环现状**：
  - 8 大分类快速过滤器（所有、音频、文档、可执行、图片、视频、压缩包、文件夹）支持快捷键与界面点击无缝联动（达标）。
  - `size:`、`ext:`、`dm:`/`dc:` 函数全面执行过滤（达标）。
  - 隐藏/系统属性过滤已在引擎层实现，但 MFT 扫描尚未写入属性位、GUI 也未提供开关（待接线，见 §3.10-3）；路径排除规则可在配置文件中声明（达标）。

### 3.5 结果操作（Result Operations）
- **同类基线**：打开、资源管理器定位、复制路径、系统属性面板为基线操作；现代桌面端必备安全删除至回收站与重命名。
- **Cairn 闭环现状**：
  - 数据表右键上下文菜单（打开、打开所在位置、复制完整路径、复制文件名、删除、系统属性）与 Treemap 右键菜单闭环（达标）。
  - 后台服务 100% 只读（达标）；GUI 侧已通过 Win32 `IFileOperation` 实现删除到回收站，并提供回收站位置视图（浏览、还原、永久删除、清空回收站）；`F2` 重命名尚未实现（部分达标，见 §3.10-4）。
  - 协作式查询取消（`Cancel`）已存在于协议与服务端会话模型，GUI 尚未发送；服务端按连接同步处理请求，查询中途无法接收取消（待接线，见 §3.10-5）。

### 3.6 选择与键盘（Selection & Keybindings）
- **同类基线**：全键盘可达、焦点循环、快捷键覆盖率高是高生产力工具的核心标准。
- **Cairn 闭环现状**：
  - 核心快捷键已绑定（达标）：`Ctrl+F`/`Alt+D`/`F3` 聚焦、`Tab` 切焦点、`Ctrl+Shift+C` 复制全路径、`Ctrl+Shift+N` 复制文件名、`Ctrl+C` 复制选中文本或路径；应用级全局缩放仍未绑定；Treemap 画布内 `Ctrl+0` / `Ctrl+=` / `Ctrl+-` 已绑定。
  - 单选与 Ctrl 多选已实现（达标）；Shift 连续区间选择尚未接线（待接线）。
  - 命名互斥体单实例与托盘显示/退出已实现（达标）；全局热键尚未接线（待接线）。

### 3.7 索引引擎与规模（Indexing & Scale）
- **同类基线**：流式读取 `$MFT` 结合 USN 变更追赶，无日志卷支持快照降级。
- **Cairn 闭环现状**：
  - 盘符枚举与流式分块读取 MFT 已实现（达标）；卷 GUID 当前是占位值（`VOL_C:`），`$BITMAP` 预跳过尚未实现（待接线）。
  - USN Journal 500ms 轮询追赶，删除事件优先判定（达标）。
  - 无日志卷优雅降级为 `SnapshotMode` 快照模式并支持低频定时重新扫描（达标）。
  - 索引持久化缓存具备魔数、版本头与校验和，写盘采用原子替换（达标）。

### 3.8 系统与平台集成（System Integration）
- **同类基线**：后台 Windows 服务（LocalSystem）常驻维护多卷索引，免提权 GUI 客户端通过安全 IPC 通信。
- **Cairn 闭环现状**：
  - `cairnd.exe` 服务具备 Win32 DACL 严格安全描述符与 `PIPE_REJECT_REMOTE_CLIENTS`，仅允许本地交互用户连接（达标）。
  - 管道显式校验协议版本号，防止反序列化漏洞（达标）。
  - 索引配置由本地已认证用户经管道提交（`SetConfig`/`Rescan`/`ReloadConfig`/`ClearContentIndex`），服务校验后以 SYSTEM/Administrators 描述符原子持久化并即时应用（达标）；`admin_only_query` 只能由管理员修改（达标）。

### 3.9 本地化与偏好设置（Localization & Settings）
- **同类基线**：完整的多语言国际化架构（非硬编码），偏好设置持久化。
- **Cairn 闭环现状**：
  - `fluent-bundle` 双语支持（`zh-CN.ftl` / `en-US.ftl`），键值 100% 对齐（达标）。
  - `%APPDATA%\Cairn\settings.toml` 原子读写持久化，语言、排序列、列宽、字体缩放、开机自启生效（达标）。
  - Windows 当前用户开机自启（写入 Run 注册表键）打通（达标）。

### 3.10 能力状态与差距清单（Status & Gaps）
以下条目不计为“达标”，必须按实际状态对待：
1. **系统原生图标**（待接线）：`icon_cache.rs` 已实现双层图标缓存，但结果表尚未消费，当前使用单色矢量图标。
2. **内容检索命中片段（Snippet）**（待接线）：服务端已产出上下文片段，GUI 尚无展示入口。
3. **隐藏/系统属性**（待接线）：引擎过滤已实现，但 MFT 扫描未写入 `FLAG_HIDDEN`/`FLAG_SYSTEM`，GUI 也无开关（见 §3.4）。
4. **GUI 写操作面**（部分达标）：删除到回收站、回收站浏览/还原/永久删除/清空已实现；`F2` 重命名尚未实现；后台服务保持只读。
5. **查询取消**（待接线）：协议与服务端会话模型存在 `Cancel`，GUI 不发送；服务端按连接同步处理，查询中无法接收。
6. **表头显隐**（未实现）：列显隐与表头右键菜单未实现；列宽拖拽与持久化已落地。
7. **全局热键**（待接线）：`global-hotkey` 依赖已声明，尚未注册。
8. **Shift 连续选择**（待接线）：当前仅支持单选与 Ctrl 多选。

## 4. 功能需求规范

### 4.1 索引模块（IDX）

| 编号 | 优先级 | 需求描述 | 量化验收标准 |
|:---|:---|:---|:---|

### 4.9 磁盘空间可视化（DSV）

| 编号 | 优先级 | 需求描述 | 量化验收标准 |
|:---|:---|:---|:---|
| **DSV-01** | P0 | **自底向上尺寸聚合与全盘覆盖**：对标 SpaceSniffer 与 WizTree，全面覆盖系统卷所有核心目录（`Users`、`Windows`、`Workspace`、`Program Files`、`ProgramData` 等），严禁采用浅层硬编码截断。通过高效自底向上累加算法（`parent_idx` 引用链汇总文件物理尺寸），使整盘使用量与 Win32 卷信息精确吻合（误差 ≤ 2%） | 400 万条记录下，尺寸自底向上聚合耗时 **≤ 100ms**；核心目录尺寸准确反映实际占用 |
| **DSV-02** | P0 | **层级嵌套 Squarified Treemap 布局**：采用递归嵌套矩形树图算法（Nested Treemap），目录作为外层容器（含 20px 标题布局带与统一 2px 视觉间隙），其内部递归划分直接子项矩形；文件作为叶子实体块呈现，比例严格对应真实磁盘占用 | 宽高比优化趋近于 1:1；目录容器明确包含其真实子目录与子文件，彻底杜绝扁平单一平铺盲盒 |
| **DSV-03** | P0 | **细节级别（Level of Detail, LoD）阈值截断**：界面提供 `+` / `-` 细节级别调节（1~5 档，默认第 5 档），动态换算最小像素面积阈值与最大展开深度；微小碎屑节点自动合并或平铺，避免视觉过度拥挤 | 随窗口大小与 LoD 动态自适应；调节档位时 16ms 内瞬时重算并重绘 |
| **DSV-04** | P0 | **下钻深度流转、画布缩放与双向导航**：双击任意目录方块、选中后 Enter，或在画布内用滚轮把所需倍率 ≤4× 的真实目录放大到填满画布时进入该目录并重新展开内容；进入即直接呈现新目录内容，不播放过渡动画。滚轮以指针为锚连续缩放 1–4×（上滚放大、下滚缩小、横向忽略），不改变选中、LoD 或目录历史，缩小到 1.0 停止；`Ctrl+0` / `Ctrl+=` / `Ctrl+-` 为键盘等价。中键拖拽（仅 >100%）1:1 平移视口，画布聚焦时方向键按视口 10% 平移（100% 时消费但不移动）；状态栏在 >100% 时显示向上取整的倍率按钮，点击复位到 100% 且保留选中；`Esc` 先结束平移。Treemap 顶部不设面包屑或返回按钮，`Backspace` / `Alt+Left` 返回上一级，顶栏前进/后退与 `Alt+Right` 按目录历史导航 | 双击/Enter/自动进入行为一致、直接切换；自动进入仅对真实目录生效，所需倍率 >4× 不自动进入，并带 400ms 冷却；滚轮缩放与键盘复位不改变选中或 LoD；中键/方向键平移保持 1:1、不露画布且不改选中/缩放/LoD/历史；100% 时不移动；倍率按钮显示向上取整百分比，点击复位保留选中并归还画布焦点；`Esc` 先结束平移；根目录前进/后退禁用；不回退隐藏表格状态 |
| **DSV-05** | P0 | **类别图例筛选**：状态栏右侧提供 10 类“色块 + 本地化类别名”图例，色块直接取自对应类别的 Treemap 填充；点击任一项淡化对应类别、布局与选择不移动，末尾重置按钮恢复全部；文件名/扩展名/尺寸文本过滤仍由经典搜索表格承担，Treemap 顶部不设筛选带 | 切换即时反馈；图例标签与类别一一对应；被淡化类别仍保留可读的路径/尺寸 tooltip |
| **DSV-06** | P0 | **富交互反馈与上下文操作**：单击选中方块（显示高对比度环形边框），双击打开文件或下钻目录；右键上下文菜单提供：打开、打开所在位置、复制完整路径、复制文件名、删除（经 IFileOperation 移入回收站，日常删除使用项目统一确认框，进度/错误由原生承载）、系统属性、在表格中查看 | 右键菜单呼出顺畅；“在表格中查看”无缝联动经典搜索表格并自动应用当前路径过滤 |
| **DSV-07** | P0 | **双态隔离与经典表格保全**：左侧侧栏选择“驱动器-C盘”进入磁盘空间树图可视化；选择“位置-所有文件”严格保留经典全宽搜索表格与百万行虚拟滚动，彼此状态独立、互不侵入 | 切换导航项无延迟无闪烁；经典搜索表格零回归 |
| **DSV-08** | P0 | **回收站位置视图**：侧栏“位置”区提供回收站入口；表格列呈现名称、原位置、大小、删除日期；搜索框就地过滤回收站（名称/原位置，区分大小写）而不发起索引查询，整字/匹配路径/正则在回收站内隐藏；支持多选还原（Shell 原生还原管线）、永久删除（项目统一确认框）与清空回收站（Windows 原生警告）；选择按项目身份跨过滤/排序/刷新保留；回收站不依赖索引服务，服务离线时仍可浏览；列表读取失败时显示内联重试状态并禁用旧行操作；切换文件类型或驱动器时离开该视图；底栏显示当前可见项目数；操作失败时 toast 列出实际失败项，取消不提示 | 入口位置与计数正确；还原后项目回到原位置且从列表消失；永久删除使用项目确认框、清空保留原生警告；服务停止时仍能列出与还原；过滤无匹配与空回收站文案不混淆；骨架/结果切换表头不横向跳动；取消确认框或原生警告无 toast |
