# 索引与一致性防线

本文记录 Cairn 索引层不能退让的边界。它们是回归审查和测试设计的依据，不代表当前已有专门的端到端基准。

## 1. 数据真值与持久化

- **先落盘，再宣布同步完成**：状态上报必须基于实际持久化结果；数据库写入未确认时不得向 UI 广播 Synced。
- **原子替换**：索引/配置文件采用临时文件加原子替换；异常退出不能留下半个可解析文件。
- 数据库备份必须与主文件版本匹配；恢复流程不得把不完整备份当成有效索引。

## 2. USN 与增量修复

- 监控 USN Journal 时处理溢出、断电重置、跨卷变更和日志失效。
- 监控断线后能够回退到快速扫描/增量修复，而不是永久失联。
- 硬链接变更必须被识别；不能把链接计数变化误判为独立文件增删。
- 状态机测试必须驱动真实调用现场。只测纯辅助函数，调用现场的参数错误（例如 `tail_usn` / `had_changes`）仍可能全绿。

## 3. 并发、内存与流式查询

- 不跨线程共享可变状态；索引用锁范围要有明确边界。
- 管道查询使用超时、背压、取消和分页；不在一次响应中构造全量结果。
- 结果表使用虚拟列表，只渲染可见行；文件记录保持紧凑，文件名进入共享池，避免每节点独立堆分配。
- SSE/UI 分页拉取不得在 `render` 中触发；使用偏移钩子或 `defer`，并设置防重入标记。

### 3.1 排除规则只有一套语义（IDX-09）

- 一条规则按**路径段边界**匹配：`node_modules` 命中名为 `node_modules` 的那一段，不是 `node_modules_cache` 这类只是前缀相同的目录；带分隔符的规则（`target\debug`）命中的是整段路径序列；`C:\Users` 这类盘符前缀命中到路径段边界为止。
- 文件名查询的逐卷快速路径与内容索引管线读**同一条规则**，因此同一个文件不会在文件名查询里可见、却在内容索引中被排除（或反之）。
- 排除规则可由用户经 `SetConfig` 热改；改完不必重启服务，两条路径同时生效。

## 4. 内容索引隔离

- 内容索引默认关闭；启用后覆盖配置允许的卷与扩展名，跳过明确排除目录。
- 正文解析/索引在工作进程中完成，宿主服务不承接第三方解析器的崩溃风险。
- 首次启用需要可见的准备进度与失败原因；准备完成前不得宣称内容可搜。关闭为暂停并保留已完成内容索引以支持重开快速恢复；清空数据只在详情弹窗中二次确认后执行，不影响文件名索引。

## 5. 用户模式降级的边界

- 服务不可用时可启动用户模式索引器，但只能看到当前账户可读的文件；结果集小于服务模式是预期行为。
- 用户模式不写服务数据目录，不注册服务，不要求 UAC。
- 共享用户索引器按需启动、10–15 分钟无租约退出，由 GUI/CLI/agent 共享，单用户唯一实例，不写服务数据目录，不注册服务，不要求 UAC。用户索引器仍随父进程退出（见 `docs/SPEC.md` §3.10-12）。

## 6. 缺陷修复的验收格式

重复出现的同类缺陷必须同时交付：

1. 调用现场的精准修复；
2. 能解释复发的调用链溯源；
3. 会在缺陷重现时变红的回归测试。

测试应断言真实行为、关键边界或系统状态；不要用哈希快照、无需求的内部字符串或实现细节充当回归证据。

## 代码位置

- `crates/cairn-service/src/sync_engine/`：USN、日记账、内容索引与卷同步。
- `crates/cairn-service/src/user_mode.rs`：用户模式降级。
- `crates/cairn-core/src/engine.rs`、`crates/cairn-core/src/syntax.rs`：查询与过滤。
- `crates/cairn-core/src/treemap/`：磁盘空间扫描、CSR 目录聚合索引与嵌套布局。服务的 `GetTree` 请求从活跃卷索引直接构建目录树供 Treemap 一次往返取用（`sync_engine.rs::treemap_tree`），无索引路径由应用内渐进扫描兜底。
