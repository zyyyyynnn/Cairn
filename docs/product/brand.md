# 图标与视觉资产

## 1. 母版与尺寸

- 唯一母版：`assets/icons/cairn_icon.svg`（1024×1024）。深色圆角底板 + 六瓣白色花标，保持灰度层次与轻微浮雕。
- 允许的光栅产物：
  - `cairn-32.png`、`cairn-64.png`、`cairn-128.png`、`cairn-256.png`
  - `cairn.ico`（包含 16/32/48/256）
  - `cairn-32.rgba`（托盘）
- 不生成额外尺寸阶梯（例如 16/24/48/512/1024 PNG）；所有产物直接从母版生成，不制作简化/加粗变体。
- `assets/icons/` 是全项目唯一样本位置：exe 图标、安装包、标题栏与托盘都从这里引用，不在 crate 内保留同步副本。

## 2. 使用位置

- 标题栏：`appicon` 使用单独的 **20px**（5 × 4px）token，`Cairn` 品牌词标使用 **16px**；图标继续使用现有 32px 派生图，不新增资产、不生成额外尺寸阶梯。
- 托盘：`cairn-32.rgba`。
- PE/安装包：`cairn.ico`。
- 图标源文件不在运行时修改；更新品牌图形时先换母版，再按固定阶梯重新导出。

## 3. 生成式设计探索

- 视觉探索使用精炼中文短提示词，一次生成多组变体。
- 同一构图/隐喻经过两轮迭代仍不契合时，切换新的设计隐喻；不要在失败方向上继续微调。
- 生成结果必须人工筛选后再进入固定尺寸导出流程，不能把临时探索图直接提交为产品资产。
