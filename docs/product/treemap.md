# Treemap 磁盘空间视图规范

Treemap 呈现驱动器内文件与目录的磁盘空间占用。顶部路径带支持面包屑层级切换与路径输入，底部状态栏承载项目统计与类别筛选，键盘支持 `+`/`-` 调节细节级别（1–5 档）。

## 1. 数据与加载

- 入口：侧边栏选择驱动器；切回“所有文件”必须清除 Treemap 状态并释放部分树。
- 画布位于面板的 4px 框架卡片内。
- 数据来源按层级取用：内存中的已取回根树即时呈现；不可用时向后台服务发起一次目录树请求（`GetTree`），从活跃卷索引直接取聚合树。服务不可用或路径未被索引时，画布显示单行不可用态；未索引、不是文件夹、直接子项过多与服务不可用各有独立说明。子树条目超出单次响应预算时服务自动降低本次深度并改用汇总块，不因此进入不可用态。
- 扫描期间视口保持底板，树就绪后一次性呈现完整画布（与表格对齐）；底栏左侧显示加载图标，树构建完成前不发布计数。
- 完成取回的根树写入内存缓存，再次进入直接复用，不重新请求。
- 空目录与不可用态复用结果区的居中状态带：32px 语义图标 + 单行标题 + 可选动作；仅未索引与服务不可用提供“重试”，底栏不重复整句说明。

## 2. 类别

所有类别共用同一 fill：浅色 `#D9D9D9`、深色 `#3A3A3A`（产品灰阶的交互档）。表头与文件叶同色，层级由名称、图标、2px gutter 与嵌套矩形表达，同一类别在任何深度保持同一颜色；容器 body 保持画布色，任意深度的 2px 间隙都是同一画布色；图例只保留文字与开关状态。

- 文件只按扩展名归类，另有少数名字规则：Dockerfile、CMakeLists.txt、Cargo.toml、package.json、Makefile 属于源码，README/LICENSE/NOTICE 按词干属于文档，仅以点开头的文件名（如 `.env`、`.gitignore`）属于配置；扩展名表是唯一判定源，最后一个点后的段生效，ASCII 大小写不敏感。可执行文件、安装包与共享库属于程序；源码、配置与脚本属于文档；设计源文件属于图片；磁盘镜像属于压缩包；字体、数据库、快捷方式与日志属于其他；没有扩展名或未识别的扩展名归其他。
- 目录不按名字猜类别：目录初始为其他，随后继承子项中字节最多的内容类别；其他类别的字节仍是多数时保持其他；目录不按名字分类。
- 画布与名称 ink 直接取壳层的 `content` 与 `foreground` 角色，不另钉数值；尺寸 ink 取同一色阶的 `#3A3A3A`（浅）与 `#CECECE`（深），确保在所有类别表面达到 AA（≥4.5:1）。

### 2.1 状态摘要口径

- 未选中：`N 个项目 X`。`N` 是当前 Treemap 根目录下所有层级的项目总数（文件与目录各计 1，包含被折叠进汇总块的项）；`X` 是这些项目的递归字节总和，包含所有后代。树加载期间左侧只显示加载图标，不发布未完成计数。
- 选中普通区块：只显示名称与大小。选中汇总块：显示 `N 个项目` 与大小，不显示伪造路径。
- 完整路径、日期与占比不作为可见底栏文本，只保留在无障碍文本中。

### 2.2 图例与筛选

- 状态栏右侧只显示类别文字按钮，不设色块；点击整行切换该类别，隐藏时文字转为次级色。
- 点击整项切换该类别；被关闭的类别在原位淡化（浅色保留 42% fill、深色保留 50%，深色 fill 贴近画布，份额再低就读成间隙），不移动布局、不改变选中路径。
- tooltip 提示“隐藏/显示该类别”；末尾旋转图标恢复全部类别。
- 低于可读阈值的纹理块不参与 hover/active、tooltip 或右键菜单，也不拦截点击。

## 3. 布局

### 3.1 嵌套与间隙

- Squarified Treemap 递归嵌套；目录先占顶部表头，再在 body 内布局子项。
- 表头布局带 `20px`，可见 `18px`，剩余 `2px` 是表头与内容之间的间隙。
- 每个 tile 在布局单元格内缩进 `1px`；相邻 tile、表头与 body、画布边缘与最外层 tile 都形成统一的 `2px` 间隙，递归不叠加。
- 表头固定 `[Folder icon] [Name] [Size]`：名称半粗体截断，尺寸仅在不会挤压名称到最小可读宽度时右对齐；尺寸不带前缀符号。
- 文件/目录叶与汇总块的尺寸固定在左下角、与图标左缘对齐；块高不足时只显示名称。
- 所有目录名称（表头与紧凑目录叶）统一半粗体；文件叶和汇总名称使用 medium。

### 3.2 阈值与收口

- 所有可见区块（含汇总块与根目录）长宽比不得超过 `3:1`，宽高不得小于 `46×30px`（绘制后 `44×28px`）。
- 布局后超阈值的真实项移入尾部并重排；超阈值的汇总块先把布局权重提高到能画出可读单元格（`46×30`、不超过 `3:1`），再重排，成员不因几何下限被删除；只有画布小到任何可读块都放不下时才丢弃。
- 汇总块的显示面积可以大于其字节占比（可读下限优先于面积比例），块上的项数与大小始终是折叠成员的真实合计。
- 尺寸低于阈值的根目录并入尾部汇总，尺寸增长后恢复独立呈现，避免生成极端长条节点。
- 若目录表头与内边距导致内容区域长宽比超阈值，该目录降级为紧凑叶呈现。
- 尾部按类别折叠：一个类别一个“其余 N 项”块，按该类别字节从大到小排列，块身份为 `目录::<tail:<类别>>`，窗口尺寸只改变哪些条目进尾部，不改变某一块代表哪一类。最大的子项始终保留为独立瓦片。
- 块始终绘制：占比再小也画，放不下文字时只画色块并保留名称；它是可选中、可下潜的实体，与瓦片同构。
- 块成员索引随布局一起给出，双击/Enter 进入的画布层与块上数字天然是同一批条目，不依赖目录查询。
- 目录容器不能出现空 body；重复折叠后若没有可绘制子项，回退为最大的合规子项或紧凑叶。

### 3.3 呈现

- 区块本身没有动效：不播放逐块弹簧、进场生长或逐块错峰，树就绪后区块直接落在该次布局的精确坐标上。内容变化时淡入的是整个画布表面，时长取 `motion::MASK_DISSOLVE`；开启“减少动态效果”时直接呈现终态。
- 淡入的生命周期与尺寸变化分离：只有内容代际改变才重置动画键。窗口 resize 期间由壳层覆盖内容面板（见 [ui.md](ui.md) §1.6），画布保持原布局不逐帧重排，尺寸停止变化后重排一次并随遮罩在 150ms 内溶解；侧边栏折叠/展开期间不重算 Squarified 布局，而是把现有单元格沿宽度连续投影贴满画布，因此既无逐帧抽动，也不暴露底色，停稳后一帧内没有布局跳变。
- 绘制矩形由布局单元格内缩 1px 得到，每帧统一对齐到物理设备像素网格；命中测试使用该矩形。
- 标签阈值与文本测量使用停稳后的投影宽度（缩放系数乘以侧栏停止后的画布宽度比例），折叠与展开过程中判定不逐帧翻转，停稳时可见标签与实际绘制宽度一致。
- 选中不画外框与选择环：选中的节点及其整个子树保持完整填充（按路径分隔符边界判断，`C:\WindowsApps` 不属于 `C:\Windows`），容器 body 采用低份额同色底板（浅色 12%、深色 16%）；子树外的表头、叶子与容器 body 按淡化份额（浅色 42%、深色 50%）置灰；类别隐藏与选中同时发生时，子树内被隐藏的类别仍按类别淡化，子树外一律置灰；切换即时，无过渡。
- 布局只在 base 像素空间计算：树载入、LoD 与画布 resize 重建 base 布局；类别筛选只原地淡化，不重排；滚轮缩放不重算。滚轮只改变视图变换 `screen = (base - origin) * scale`；投影后的矩形按画布裁剪，整棵视口外子树跳过。

## 4. 交互

| 操作 | 行为 |
| --- | --- |
| 单击 tile | 选中并显示状态栏元数据；其余节点与隐藏类别一样置灰 |
| 双击目录 / Enter | 下钻并直接呈现新目录内容 |
| 双击汇总块 / Enter | 画布根变为该块折叠的那批成员（只含该类别未被单独画出的项），面包屑追加一段“其余 N 项”；层内继续按类别拆块、可继续下潜；上一级/后退回真实目录，前进可再进入该层 |
| 垂直滚轮（指针在画布内） | 以指针为锚连续缩放 1–4×：上滚放大、下滚缩小；横向滚动忽略；不改变选中、LoD 或目录历史 |
| 中键拖拽（仅 >100%） | 按住中键 1:1 平移视口，内容跟随光标；不改变选中、倍率、LoD 或目录历史；松开中键、后续移动不带中键、导航、复位或 LoD 变化时结束，`Esc` 也先结束平移 |
| 方向键（画布聚焦） | 按视口 10% 平移：`Right` 使视口向右、内容向左；100% 时消费按键但不移动 |
| 状态栏倍率按钮（仅 >100%） | 显示向上取整的当前倍率；点击复位到 100%，保留选中，焦点回到画布 |
| 放大到所需倍率 ≤4× 的真实目录填满画布 | 自动下钻该目录；文件与汇总块不触发；一次自动进入后 400ms 冷却；所需倍率 >4× 的目录不自动进入，仍可双击/Enter 下钻 |
| `Ctrl+0` / `Ctrl+=` / `Ctrl+-` | 在 Treemap 画布内复位视图 / 放大 / 缩小（键盘等价，不自动下钻） |
| `Backspace` / `Alt+Left` / 顶栏后退 | 按历史后退；块层是一步历史，后退先离开块层；下钻、面包屑跳转与上一级都记入历史 |
| `Alt+Up` / 顶栏上一级 | 有块层时先离开块层，否则进入父目录并记入历史；根目录禁用 |
| `Alt+Right` / 顶栏前进 | 按历史前进；后退离开块层后前进重新进入该层；块层内部没有前进 |
| 点击面包屑任一级，或聚焦祖先面包屑后按 `Enter` / `Space` | 进入该目录并记入历史；当前目录不可点击 |
| 点击某段面包屑右侧箭头，或聚焦后按 `Enter` / `Space` | 打开该段的子文件夹下拉；箭头闭合时指向右、打开时指向下，重复点击关闭。菜单读取该目录的实时列表，跳过带隐藏或系统属性的条目（含目录联接本身）；扫描凑满 100 个即停止读取该目录，取到的条目按显示名自然排序，因此超出上限时列出的是目录顺序中靠前的合格子文件夹而非字典序前 100 个。没有可选子文件夹时底部说明“没有可切换的子文件夹”，超出上限时说明“仅列出前 100 个文件夹”。选中条目直接进入该目录并记入历史。宽度按实测最长名称自适应，介于 224px 与 336px 之间；单个名称的列宽上限为 20rem，超出部分以省略号收尾，tooltip 给出完整路径 |
| 点击路径栏空白 / `Alt+D` / `Ctrl+F` / `F3` | 路径栏转为输入框并全选当前路径；可直接输入驱动器绝对路径或相对当前文件夹的路径（支持 `..`、引号、正/反斜杠） |
| 路径栏 `Enter` / `Tab` | 打开输入的目录；格式无效时保留编辑态、危险色描边并提示。服务按原因返回：未索引、不是文件夹、直接子项过多或服务不可用；四种原因各有单行说明，仅未索引与服务不可用提供重试 |
| 路径栏清除按钮 | 指针清空输入并保持编辑；输入为空时按钮隐藏，位置与搜索框清除控件一致。键盘用全选后删除清空；Tab 从输入框提交路径，不会丢弃已输入内容 |
| 路径栏 `Escape` / 失焦 | 取消编辑，恢复面包屑，不改变当前目录 |
| `+` / `-` | 调整 LoD（1–5） |
| `Esc` | 先结束平移；没有平移时取消选中；不隐藏窗口、不清空隐藏的查询 |
| 右键 tile | 打开、打开所在位置、复制路径/文件名、删除（项目统一确认框，成功后移入回收站）、属性、在表格中查看 |
| 右键汇总块 | 只放对块成立的项：在表格中查看（列所属目录）；下钻由双击/Enter 承担，右键不提供“打开”；复制名称/复制路径/删除/属性/打开所在位置不出现 |
| 点击画布空白或窗口其他区域 | 取消选中 |

- 每个归一化滚轮行按 `1.12×` 乘法步进，单次事件最多 3 步。Pixels 以 `120px = 1 line` 归一化；Windows 的 `Lines` 一格通常是系统滚轮行数（默认 3 行），因此除以 3，使鼠标一格约等于 1 步。缩小到 `1.0` 停止，原点归零；最大 `4.0×`。缩放不改布局、不重新选节点，也不展开更多层级。
- 滚轮本身不改变选中、LoD 或目录历史。自动进入与双击/Enter 一样是一次新的分支下钻：进入新目录、记入后退历史并清空 Forward 栈；键盘缩放与 `Ctrl+0` 复位从不自动进入。
- 自动进入以 base 布局矩形计算“刚好填满画布”的所需倍率：`max(canvas_w/rect_w, canvas_h/rect_h)`，结果不封顶。仅当 `required ≤ 4.0` 且当前 `scale ≥ required` 时进入；`required > 4.0` 的目录不会在 4× 被误判为填满，保留双击/Enter 路径。指针命中使用四边内缩 `1px` 的绘制矩形，tile 之间的 gutter 归父容器。
- Hover / Active 在目录表头、文件叶、紧凑目录叶和汇总块上按自身表面下压 HSL 明度：浅色 `-0.035 / -0.065`，深色 `-0.03 / -0.055`；保持色相与饱和度，无边框。hover 相对初始态 ≥2.5 CIE76、active ≥4.5 CIE76，两态对画布均 ≥ `1.10:1`，两档 ink 在两态上仍分别保持 AAA 与 AA；亮度比单独不足以判定近黑表面上的状态变化。
- 汇总块是可选中实体：单击选中该汇总块；hover/active 与普通区块一致；tooltip 第一行是“其余 N 项”、第二行是折叠项的总大小；块没有真实路径，路径相关动作不进入它的菜单。
- 目录容器本身不响应 hover/active；只有表头和内部 tile 响应，避免祖先连锁高亮。

## 5. 测试与代码

app 层按特征目录组织（`search/`、`table/`、`treemap/`、`service/`、`shell/`），目录内文件名不带板块前缀。

- `crates/cairn-core/src/treemap/`：核心 Treemap 领域组件（`geometry` 领域矩形、`path`、`category`、`tree`、`squarify`、`index` CSR 目录聚合索引、`layout` 嵌套布局与 3:1/最小尺寸收口及回归测试），统一经 `cairn_core::treemap` 导出。
- `crates/cairn-app/src/treemap/`：应用层 Treemap 模块（`view` 画布渲染与交互、`path_band` 路径带与面包屑、`scan` 导航与扫描生命周期、`context_menu` 区块右键菜单、`state` 视图状态与增量事件消费、`navigation` 目录历史与路径包含判定、`paint` 绘制矩形、设备像素对齐与文本测量、`zoom` 视图变换与指针锚点缩放、`palette` 类别色板与对比度测试）。
- `crates/cairn-app/src/shell/status_bar_view.rs`：状态摘要与类别图例。
