# UI 规范

> Treemap 见 [treemap.md](treemap.md)；品牌图标见 [brand.md](brand.md)。

## 1. 界面排版与视觉设计规范

### 1.1 现代高密度四段式工作区架构
四段式垂直高密度工作区结构：
1. **顶部窗体栏（TitleBar）**：纯净系统窗体，承载系统品牌标识与全局窗口级核心导航。
2. **主搜索带（Search Band）**：位于主内容区顶部，全宽主搜索输入框；匹配选项通过顶栏“搜索”菜单和快捷键切换，输入框不内嵌独立触发器，主内容区不设面包屑与独立筛选行。
3. **百万行虚拟数据表（DataTable）**：表头直接直连搜索带下沿，行内以等宽数字高密度呈现。
4. **底部状态栏（StatusBar）**：表格视图只展示当前结果的对象计数；Treemap 视图在同一高度展示目录/选中项摘要与类别图例，不放搜索提示或卷状态。

### 1.2 窗口尺寸基准与高 DPI 缩放预算
- **默认窗口尺寸**：`1280 × 800` 逻辑像素。
- **最小窗口尺寸**：`1024 × 640` 逻辑像素。
- **物理像素预算考量**：
  在 Windows 1.6× 系统 DPI 缩放与 208px 侧边栏展开状态下，表头四列下限为名称 168px、路径 112px、大小 84px、修改时间 132px，合计 496px；加列内边距后仍低于 `1024px` 最小窗口的可用内容宽度。`1280px` 默认宽度则可使名称与路径列拥有充裕的展开呼吸感。

### 1.3 纯净 TitleBar 窗体栏规范（高度 34px，与 gpui-kit `TITLE_BAR_HEIGHT` 一致）
- 右侧三个窗口控件使用 GPUI Kit 标准 caption 控件的几何：每个控件宽 `34px`、占满标题栏高度、图标 `16px` 居中；不使用自定义绘制的图形。Windows client-side decoration 由 GPUI 绘制图标，点击、贴靠布局和系统提示仍由 `window_control_area` 交给平台处理。
- 保持系统级沉浸与高雅，左侧控件排布自左至右**严格依序**：
  `appicon`（应用微标） → `Cairn`（Cormorant SemiBold 品牌词标） → `nav-back` / `nav-forward`（前进 / 后退导航按钮） → `sidebar-toggle`（侧栏折叠汉堡按钮） → 顶栏菜单栏（`文件` / `编辑` / `查看` / `搜索` / `工具` / `帮助`）。
- `appicon` 使用 `assets/icons/cairn_icon.svg` 主文件：深色圆角底板、白色六瓣标记；32/64/128/256 PNG、ICO 与 32px RGBA 全部由该主文件直接渲染，不修改 SVG 源文件，也不扩充成套分辨率。顶栏按 22px 显示 32px 派生图，在花瓣辨识度与品牌行重量之间取平衡。
- 标题栏在侧边栏宽度（208px）处与下方侧边栏保持同列，但标题栏内不绘制纵向分割线；分割线只属于下方侧边栏。`appicon` 与 `Cairn` 在左半区左对齐，`nav-back` / `nav-forward` / `sidebar-toggle` 在左半区右对齐；菜单栏在右半区自侧边栏列宽后左对齐。
- 标题栏几何固定：侧栏折叠/展开只隐藏或显示下方导航树，标题栏始终无分割线，左半区仍保留 208px，菜单栏、导航按钮和品牌都不发生水平位移。
- 标题栏 app-icon、侧栏组标题首字与导航行图标的左缘共用 **12px 内容脊柱**；图标与文字各自在行内垂直居中。折叠后 app-icon 与内容列的搜索图标、名称表头、结果行图标继续共用 12px 左缘。
- 内容列的菜单首字、搜索框放大镜图标与表头“名称”也共用该 12px 左缘；不通过中心槽或文字缩进改变这条脊柱。
- 菜单栏与品牌同行，是窗口完整命令与设置的入口；不在搜索带重复放置同一组菜单，也不在“查看”菜单重复放置标题栏已有的侧边栏开关。
- 不在此栏放置面包屑路径，维持窗体克制感。
- 右侧仅保留 Windows 原生窗口控制按钮（最小化、最大化、关闭）。

### 1.4 主搜索带规范（高度 40px）
- 位于主内容列最上方，与侧边栏平齐：
  - **主搜索框**：全宽水平延伸，提供充裕的文本输入与表达式编辑空间。搜索框上下外缘各留 4px，左右外缘各留 4px 对称边距，框内左右内边距各 8px。
  - **匹配选项**：大小写、全字、匹配路径、正则表达式由顶栏“搜索”菜单和 `Ctrl+I` / `Ctrl+B` / `Ctrl+U` / `Ctrl+R` 切换，搜索框内不设匹配选项按钮。正文检索不使用查询开关，统一用 `content:` 语法，并由工具菜单索引项的单一“内容检索”总开关控制可用性。

### 1.5 百万行虚拟数据表格与列对齐规范
- **表头**：高 `28px`，与结果行同高，背景为浅灰底色，与搜索带直接贴合无缝直连。列间以细竖线分隔，当前排序列显示升降序微型矢量指示符（`ChevronUp` / `ChevronDown`）。名称表头与结果行图标同左缘，名称值随行图标后起始。右侧滚动条槽位从第一帧起固定预留，骨架、空态和结果态共用同一列宽，加载完成时表头不得横向跳动。
- **行高**：固定为 `28px`，支持字体缩放（`Ctrl++` / `Ctrl+-` / `Ctrl+0` 待接线；当前可从“查看 > 缩放”选择三档）。
- **底部软边阴影**：结果区底边在仍有内容可继续滚动时，以 `12px` 单段渐变叠加 12% 次级墨色软边阴影，提示下方还有内容；阴影横跨结果区与竖向滚动条槽位，底部边缘保持连续，不擦除行文字，也不改变 hover 与选中底色，避免把交互态误读成禁用态。接近列表末尾的最后一行内强度递减，滚到底部时完全消失。阴影层不参与命中测试，滚轮与点击仍落到行与滚动条上；横向滚动条保持独立控件，不叠加该阴影。**顶部不设阴影**：表头是稳定的阅读边界，顶部渐隐会削弱首行身份并与表头底线抢层级；需要提示“上方还有内容”时以滚动条位置为准。
- **侧栏行高**：`28px`，与结果行使用同一 `ROW_HEIGHT`；左右外缘各 4px、行内左右内边距 8px，选中行底色左右对称。
- **列对齐与格式**：
  - `名称 (Name)`：左对齐，前置单色灰阶语义图标，命中关键词应用高亮底色切片渲染。图标按扩展名区分快捷方式、文档、表格、图片、音频、视频、压缩包、代码/配置、可执行文件、字体与系统组件；文件夹固定文件夹图标，未知类型回退通用文件图标。Windows Shell 隐藏扩展名时（如回收站里的 `.lnk`）从 shell 负载路径取真实扩展名，不按显示名称猜测。
  - `路径 (Path)`：左对齐，次级灰色文本，超出宽度尾部自动截断。
  - `大小 (Size)`：左对齐，等宽数字字体（`tabular-nums`），格式化为 `B / KB / MB / GB`，与表头“大小”统一左对齐。文件显示自身逻辑大小；文件夹显示索引内全部后代文件的逻辑大小之和，随 USN 变更实时维护，并参与同一列的排序与 `size:` 过滤。junction 不跟随，排除项不计入。
  - `修改时间 (Date Modified)`：左对齐，等宽数字字体，格式化为 `YYYY.MM.DD HH:mm`，按本机时区显示。
- **回收站视图的列语义**：同一张表在回收站位置下把路径列命名为“原位置”、日期列命名为“删除日期”；排序、列宽与拖拽行为不变。表头和无障碍名称都必须反映这个语义差异，不得沿用“修改日期”。

### 1.6 结果区状态规范（骨架、空态与索引模式）
- **启动即“所有文件”**：窗口打开后先显示表头；普通首屏查询目标 **≤180ms**，超过目标才让骨架渐显；索引确实在重建、本地扫描或 USN 追赶时立即显示骨架。不存在“就绪空态”或“请输入关键词”的占位页面。空查询本身就是一条返回全部索引的查询。
- **渐进加载**：骨架行以 1.4s 周期、30fps 的行间波形脉动（行与行相位错开，遵循系统“减少动态效果”设置）；首屏行以 140ms 淡入接替骨架。索引仍在扫描/追赶时，已有结果继续显示并随状态轮询增量刷新；后台刷新不得清空已显示的行，也不得用骨架替换表格。
- **空态只表达两个事实**：查询无匹配（“没有匹配的文件或文件夹”，附带调整筛选的指引），或索引确实为空（说明索引范围）。不得把“后台服务未运行”作为阻断式空态。所有模块的空态复用同一图标尺寸、间距、标题/说明字体和动作位置，不得各自漂移。
- **回收站空态**：“回收站为空”，说明删除的项目会先到这里并可还原或永久删除。回收站不依赖索引服务：服务停止时仍显示列表或空态，不显示离线阻断带。过滤无匹配时显示“回收站中没有匹配的项目”，清空过滤由搜索框右侧的清除按钮完成，空态不再重复一个“清空搜索”按钮；判断是否为空必须基于全量列表，不能因为过滤词残留而把空回收站误报成无匹配。
- **索引来源只在“工具”菜单中说明**：底栏不承载索引模式或卷状态；顶栏“工具”菜单以只读状态行说明当前来源与覆盖范围，默认是“后台服务运行中”，不提供多余的启动按钮。只有服务问题带在服务已安装但未运行时才显示恢复入口。按卷的同步/快照状态在侧边栏驱动器行内展示，均为中性信息，只有卷离线才使用警示语义。
- **真正的错误态**：仅当服务与本地索引器都无法启动时出现，指明哪一步失败以及可执行的恢复动作（重新安装/重启后重试），不得用泛化错误或无恢复路径的提示。

### 1.7 紧凑侧边栏与间距呼吸感规范
- 侧边栏宽度 `208px`，支持快捷键或顶栏按钮快速折叠为图标模式或隐藏。
- “位置”区在文件类型行之后、驱动器区之前提供“回收站”入口；回收站是位置而不是筛选分类，任一文件类型行与回收站不能同时显示为选中。
- 选项间距：菜单项外层容器注入 `4px` 垂直间隙（`.my(px(2.0))`），杜绝 hover 态与选中态粘连。
- 卷状态只出现一次：卷列表在驱动器盘符旁保留同步/快照状态文本，底栏不重复显示。

### 1.8 底部状态栏规范（高度 28px）
- **表格视图**：显示当前结果的对象计数（如 `1,071,710 个项目`），使用等宽数字，结果刷新时数字不抖动。首屏查询、翻页或索引扫描时，计数前显示与 Treemap 相同的旋转加载图标；加载结束图标消失、数字就地更新，不另起一行状态文案。
- **回收站视图**：使用同一条计数格式显示当前可见（过滤后）项目数；列表非空且可读时，右侧提供“清空回收站”动作，加载中、不可读或空列表时隐藏；还原、永久删除或清空后计数随重新读取的列表更新。列表不可读时显示“回收站不可用”，不把 0 当成真实计数。
- **Treemap 视图**：未选中时左侧显示“当前目录全部项目数 + 占用”（项目为文件/目录各计 1，包含所有层级与被折叠项；大小包含所有后代）；选中时只显示名称与大小；树加载期间同一格式仅前置加载图标（与表格板块同规范）；右侧显示类别图例。同一状态栏高度，不显示卷状态或全局搜索提示。
- **图例与动作尺寸**：类别图例的行高、色块、间距与内缩分别取 `layout::LEGEND_ROW`、`LEGEND_SWATCH`、`SPACE_8`、`SPACE_4`、`LEGEND_INSET`，全部随 rem 缩放；2px 内缩是光学例外。“清空回收站”和 Treemap 缩放复位使用 `small` 按钮、500 字重与 12.25px 文本，保持 24px 最小操作高度。
- **共同约束**：不显示本地索引胶囊或各卷同步状态；卷状态由侧边栏驱动器行承载。Treemap 树加载进度是唯一出现在底栏的加载反馈。

### 1.9 顶栏菜单与完整设置项
- **同一行**：顶栏最左侧是 `appicon`，随后是 `Cairn` 品牌词标、前进/后退/侧栏按钮，以及 `文件` / `编辑` / `查看` / `搜索` / `工具` / `帮助` 六个菜单；不新增第二条菜单带。
- **文件**：打开、打开所在位置、属性、删除。回收站视图下改为打开、还原、永久删除、清空回收站；普通删除使用项目统一的“删除”确认框，正文说明会移到回收站、之后可还原；永久删除使用同一项目确认框，标题与动作写“永久删除”，清空回收站保留 Windows 原生不可逆操作警告。**编辑**：撤销、重做、剪切、复制路径、复制名称、粘贴、全选搜索文本、清空搜索。**搜索**：区分大小写、全字、匹配路径、正则。回收站过滤只支持名称/原位置子串与区分大小写，因此整字、匹配路径、正则三项在回收站内隐藏，避免可勾选但不生效。**帮助**：关于 Cairn。正文检索不使用查询开关，统一用 `content:` 语法。
- **查看**：排序、主题、缩放三个子菜单。侧边栏开关只由标题栏左侧的按钮承载；文件类型只由左侧导航承载，二者都不在“查看”中重复。
- **工具（设置入口）**：语言子菜单（系统/简中/EN）、启动（开机自启）、索引区分组。索引不独立成页，所有索引状态与操作都是工具菜单内的独立菜单项。
- **索引菜单项**：索引来源为只读项；内容检索总开关为可勾选项，标签携带“已关闭 / 回填中 x / y / 已就绪 / 失败”状态；其下提供取消回填、重试内容索引、清空内容索引三个动作项。清空是破坏性操作，必须先经过确认对话框。
- **索引来源**：后台服务随安装默认安装并由 SCM 运行；正常状态只说明“后台服务 · 全盘索引”，本地降级说明“本地索引 · 仅当前账户可读文件”。来源由运行时自动选择，不提供多余的启动按钮。
- **内容检索总开关**：默认关闭；打开后立即在后台回填所有已索引卷的合格文件，菜单标签显示进度，可取消或重试；回填完成前 `content:` 查询说明“索引未就绪”。关闭后释放内容索引器与 Worker。普通查询仍只匹配文件名/路径。本地降级不支持内容索引，总开关禁用并说明原因。
- **无设置弹窗**：菜单选择即时生效；索引不设独立页面或弹窗，只有清空动作使用一次性确认对话框。

### 1.10 灰阶语义令牌表（Grayscale Tokens）
所有 UI 组件严格绑定以下灰阶语义令牌，严禁硬编码任何非灰阶彩色值。所有组件外框、分割线与焦点指示统一为 **1px 极细线**，不使用 2px/3px 描边或外扩焦点环。间距统一为 **4px 阶梯**：文字保持紧凑的 `BASE_FONT_PX = 14px`，布局步长以 `4px / 14px` rem 表示，100% 缩放时所有布局 token 均为整 4px 倍数；同值与低频 token 合并。圆角统一为 **单一 3px**：应用层所有搜索框、侧栏行、骨架条与焦点框共用 `radius = 3px`，框架按钮与弹层同步使用 `theme.radius = 3px`，不设多档圆角。1px 描边、2px 光学补偿与平台标题栏尺寸作为明确例外：

| 语义角色 | 用途 | 当前实现 |
|:---|:---|:---|
| `background` / `foreground` | 画布与主 ink | `ShellTokens.background` / `foreground`；已验证 `#F9F9F9/#101010` 与 `#101010/#F9F9F9` |
| `muted` / `muted_foreground` | 下沉表面、旁注与占位符 | `ShellTokens.muted` / `muted_foreground` |
| `row_hover` | 列表行 hover；结果行选中复用同一填充 | `theme.list_hover`；已验证 `#E6E6E6/#242424` |
| `selection` | 搜索框文本选区 | `theme.selection`；已验证 `#D9D9D9/#383838` |
| `border` / `ring` | 1px 结构线与键盘焦点 | `ShellTokens.border` / `ring` |
| `status_bar` / `table_head` | 状态栏与列头带表面 | `ShellTokens.status_bar` / `table_head` |
| `warning` / `danger` | 唯一的状态语义色 | `ShellTokens.warning` / `danger` |
| 文本命中 | 结果名称/路径命中 | 使用 `foreground` + semibold；不使用背景高亮 token |

精确 HSL/hex 值由 `ShellTokens`/`theme.rs` 持有；本表只记录职责，避免文档与主题双写。

### 1.11 完备键盘快捷键流转表（对齐 Everything 经典规范）

> 标注“待接线”的组合尚未在当前 keymap 绑定，实现状态以 `crates/cairn-app/src/commands.rs` 为准；不得在 UI 中把这些键作为已可用的提示展示。

| 快捷键 | 作用域 | 对应行为定义 |
|:---|:---|:---|
| `Ctrl+F` / `F3` / `Alt+D` | 全局窗口 | 立即聚焦主搜索输入框并全选现有文本 |
| `Esc` | 全局窗口 | 搜索框有输入时清空输入；搜索框为空时隐藏窗口至托盘或最小化 |
| `Tab` / `Shift+Tab` | 全局窗口 | 在搜索输入框、侧边栏与结果表格之间循环切换焦点 |

### 1.12 回收站位置视图
- **入口与状态**：侧栏“位置”区的“回收站”是独立位置；进入后底栏显示当前可见项目数。搜索框占位为“搜索回收站…”，就地匹配名称与原位置（支持区分大小写），不发起索引查询；整字/匹配路径/正则在回收站内隐藏。切换文件类型或驱动器时离开回收站。
- **数据来源**：项目来自 Windows Shell 回收站命名空间，不经过 Cairn 索引；服务停止时仍可浏览、还原或永久删除。列表按当前表头排序，大数据量沿用表格虚拟化与本地分页。
- **选择**：选择以项目身份而非行号保存；过滤、排序、刷新后仍在列表中的项目保持选中，过滤暂时隐藏的项目在清空过滤后恢复选中。深页选择不因只加载首页而丢失。
- **操作**：`Enter` 从回收站负载打开；右键菜单提供打开、还原、复制原位置、复制文件名、永久删除；文件菜单与底栏右侧均提供清空回收站（Windows 原生确认）。还原成功后项目回到原位置并从列表消失；原目录不存在时由应用重建。
- **确认策略**：普通删除使用项目统一确认框，动作名统一为“删除”，正文说明会移到回收站、之后可还原；永久删除使用与普通删除相同的项目确认框，标题与动作写“永久删除”，正文说明不可还原；清空回收站保留 Windows 原生警告。回收站内的删除是永久操作，不与普通删除共用“删除”。
- **失败反馈**：取消项目确认框或原生警告不是失败，不显示 toast；真实失败只显示一条项目自有视觉语言的 toast，列出 shell 实际未能处理的项（最多 3 个，其余写“还有 N 个项目”）和本地化原因，原始 HRESULT 只进入日志。列表本身读取失败时进入内联“无法读取回收站 + 重试”状态并禁用项目操作，不用旧行冒充最新状态。
- **列语义**：路径列显示“原位置”，日期列显示“删除日期”（按本机时区显示）；两者都参与排序，查看菜单的排序子菜单使用同一组名称。
- **空态**：回收站为空时说明删除的项目会先到这里；过滤无匹配时说明“没有匹配的项目”，清空由搜索框的清除按钮完成，不误报为空回收站。空态和页面其它空态共用同一套图标、间距和字体。

### 1.13 瞬时状态（toast）
- 使用应用自有表面，不直接暴露组件库默认通知样式：`background` + 1px `border` + 3px 圆角、右上角固定宽度、紧凑内边距、16px 语义图标、`text_sm` 标题与 12.25px 说明，说明行高 1.5，与表格和侧栏共用同一套 `ShellTokens`。
- 信息类 toast 6 秒后自动消失；错误类持续到用户关闭或按 `Esc`，因为错误承载操作结果，不能在读清前消失。关闭按钮始终可见并有可访问名称；toast 本身报告 Alert。
- 失败文案列出 shell 实际未能处理的项（最多 3 个，其余写“还有 N 个项目”）和本地化原因；原始 HRESULT 只写日志；取消不产生 toast。

### 1.14 确认弹层
- **动作词**：普通删除的标题与主按钮都写“删除”；“移到回收站”只作为正文里的机制说明，不作为动作名。回收站内的永久删除写“永久删除”，并沿用同一弹层几何与按钮尺寸。
- **模态呈现**：使用主题遮罩（浅色 18%、深色 38%），宽 384px（100%，随界面缩放），按约 150px 的估算内容高度（随缩放）定位在窗口中段；不沿用组件库默认的 448px 宽、顶部 10% 与 6rem 最小高度，避免读成悬浮 toast。
- **按钮与关闭**：底部按钮使用标准中号尺寸，取消在左、动作在右；动作按钮使用 `danger` 语义而不是普通主按钮，取消保持次级；`Esc` 关闭且不执行，确认后才进入 shell 删除流程。
- **动效**：确认弹层以短距离淡入下滑入场；关闭立即移除，不伪造无内容的退场帧（当前上游弹层没有关闭阶段）。toast 以 140ms 淡入并上移入场，离场时反向淡出下移；减少动态效果时两者都直接呈现终态。

## 2. 当前实现核对

- 基准字号 `BASE_FONT_PX = 14px`，小字号 `SMALL_TEXT_SIZE = 12.25px`（0.875rem），标题 16px，对话框标题 14px；布局步长为 `4px / 14px`；控件 `32px`、结果/侧栏行 `28px`、列头 `28px`、搜索带 `40px`、状态栏 `28px`。
- 产品文本按钮统一 500 字重；正文与表格内容 400；选中行与 toast 标题 500。中文标题使用内嵌思源宋体 Regular，西文标题与字标使用 Cormorant SemiBold；中西文混排按文字脚本拆分，共享标点随中文标题使用宋体。
- 侧边栏默认 `208px`、最小 `152px`；窗口默认 `1280×800`、最小 `1024×640`。
- 侧栏“位置”“驱动器”等分段标题使用 16px 衬线标题（中文内嵌宋体、西文 Cormorant），行高 1.25；导航行保持 12.25px 无衬线，与分段标题形成层级。
- 全应用 `1px` 边框、`3px` 圆角；标题栏 32px PNG 按 `22px` 绘制。
- Treemap 不设顶部概览带/面包屑/LoD 控件；导航与类别筛选由键盘和状态栏承担。
- 用户界面不渲染原始 URL、物理路径、内部 token、调试枚举、命令行或开发日志；调试信息只进入开发者控制台/内部日志。
- 视觉改动必须捕获当前窗口的新截图；历史截图不得作为最新验收证据。
