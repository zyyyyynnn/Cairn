# UI 规范

> 品牌图标见 [brand.md](brand.md)。

## 1. 界面排版与视觉设计规范

### 1.1 现代高密度四段式工作区架构
四段式垂直高密度工作区结构：
1. **顶部窗体栏（TitleBar）**：纯净系统窗体，承载系统品牌标识与全局窗口级核心导航。
2. **主搜索带（Search Band）**：位于主内容区顶部，全宽主搜索输入框；匹配选项通过顶栏“搜索”菜单和快捷键切换，输入框不内嵌独立触发器；表格主内容区不设面包屑与独立筛选行。
3. **百万行虚拟数据表（DataTable）**：表头直接直连搜索带下沿，行内以等宽数字高密度呈现。
4. **底部状态栏（StatusBar）**：展示当前结果的对象计数与这批条目所占空间，不放搜索提示或卷状态。

主内容区仅承载上述搜索带、数据表与状态栏；其余能力入口集中于顶栏菜单与快捷键。

### 1.2 窗口尺寸基准与高 DPI 缩放预算
- **默认窗口尺寸**：`1280 × 800` 逻辑像素。
- **最小窗口尺寸**：`1280 × 800` 逻辑像素。
- **物理像素预算考量**：
  在 Windows 1.6× 系统 DPI 缩放与 208px 侧边栏展开状态下，表头四列下限为名称 168px、位置 112px、大小 84px、修改时间 132px，合计 496px；连同侧边栏与列内边距，壳层无法压缩的宽度约为 780px，仍小于 `1280px` 窗口的可用内容宽度，名称与位置两列因此有充足余量，四列下限不构成窗口宽度约束。

### 1.3 纯净 TitleBar 窗体栏规范（高度 34px，与 gpui-kit `TITLE_BAR_HEIGHT` 一致）
- 右侧三个窗口控件使用 GPUI Kit 标准 caption 控件的几何：每个控件宽 `34px`、占满标题栏高度、图标 `16px` 居中；不使用自定义绘制的图形。Windows client-side decoration 由 GPUI 绘制图标，点击、贴靠布局和系统提示仍由 `window_control_area` 交给平台处理。
- 左侧控件排布自左至右依次为：
  `appicon`（应用微标） → `Cairn`（Cormorant SemiBold 品牌词标） → `nav-back` / `nav-forward`（后退 / 前进导航按钮） → `sidebar-toggle`（侧栏折叠汉堡按钮） → 顶栏菜单栏（`文件` / `编辑` / `查看` / `搜索` / `索引` / `工具` / `帮助`）。
- `appicon` 使用 `assets/icons/cairn_icon.svg` 主文件：深色圆角底板、白色六瓣标记；32/64/128/256 PNG、ICO 与 32px RGBA 全部由该主文件直接渲染，不修改 SVG 源文件，也不扩充成套分辨率。顶栏按 20px 显示 32px 派生图，
- 标题栏在侧边栏宽度（208px）处与下方侧边栏保持同列，但标题栏内不绘制纵向分割线；分割线只属于下方侧边栏。`appicon` 与 `Cairn` 在左半区左对齐，`nav-back` / `nav-forward` / `sidebar-toggle` 在左半区右对齐；菜单栏在右半区自侧边栏列宽后左对齐，触发器外缘与搜索框、结果面板同处 4px 内容边缘。
- 标题栏几何固定：侧栏折叠/展开只隐藏或显示下方导航树，标题栏始终无分割线，左半区仍保留 208px，菜单栏、导航按钮和品牌都不发生水平位移。
- 标题栏 app-icon、侧栏组标题首字与导航行图标的左缘共用 **12px 内容脊柱**；图标与文字各自在行内垂直居中。折叠后 app-icon 与内容列的搜索图标、名称表头、结果行图标继续共用 12px 左缘。
- 内容列的菜单文字、搜索框放大镜图标与表头“名称”也共用该 12px 左缘；不通过中心槽或文字缩进改变这条脊柱。
- 菜单栏与品牌同行，是窗口完整命令与设置的入口；不在搜索带重复放置同一组菜单，也不在“查看”菜单重复放置标题栏已有的侧边栏开关。
- 此栏只放导航按钮，不放面包屑路径。
- 右侧仅保留 Windows 原生窗口控制按钮（最小化、最大化、关闭）。

### 1.4 主搜索带规范（高度 36px）
- 位于主内容列最上方，与侧边栏平齐：
  - **主搜索框**：全宽水平延伸，提供充裕的文本输入与表达式编辑空间。搜索框上下外缘各留 4px，左右外缘各留 4px 对称边距，框内左右内边距各 8px。
  - **匹配选项**：大小写、全字、匹配路径、正则表达式由顶栏“搜索”菜单和 `Ctrl+I` / `Ctrl+B` / `Ctrl+U` / `Ctrl+R` 切换，搜索框内不设匹配选项按钮。
  - **内容搜索**：不使用查询开关，统一用 `content:` 语法，并由“索引 > 内容索引”子菜单的单一“搜索文件内容”开关控制可用性。

### 1.5 百万行虚拟数据表格与列对齐规范
- **表头**：高 `28px`，与结果行同高，背景与结果主体同为主题白；表头与结果主体为 3px 圆角内容面板，四边留 4px 框架间距；名称列在卡片内以 8px 领先，与卡片间距合并为 12px 内容脊柱；四角以框架色路径遮罩切出圆角，遮罩不参与布局与命中，表头位置不变。列间以细竖线分隔，当前排序列显示升降序微型矢量指示符（`ChevronUp` / `ChevronDown`）。名称表头与结果行图标同左缘，名称值随行图标后起始。右侧滚动条槽位从第一帧起固定预留，空态和结果态共用同一列宽，数据呈现时表头不得横向跳动。
- **行高**：固定为 `28px`，支持字体缩放（`Ctrl+=` / `Ctrl++` / `Ctrl+-` / `Ctrl+0` 及“查看 > 缩放”三档）。
- **侧栏行高**：`28px`，与结果行使用同一 `ROW_HEIGHT`；左右外缘各 4px、行内左右内边距 8px，选中行底色左右对称。
- **首行与表头对齐**：“位置”标题与搜索带共用同一居中标题盒，上下留白一致；“位置”在搜索带高度内垂直居中，首个导航行“所有文件”与表头同为 28px 且上下边完全对齐；滚动与缩放保持该关系。
- **列对齐与格式**：
  - `名称 (Name)`：左对齐，前置单色灰阶语义图标，命中区间以加粗字重呈现。图标按扩展名区分快捷方式、文档、表格、图片、音频、视频、压缩包、代码/配置、可执行文件、字体与系统组件；文件夹固定文件夹图标，未知类型回退通用文件图标。Windows Shell 隐藏扩展名时（如回收站里的 `.lnk`）从 shell 负载路径取真实扩展名，不按显示名称猜测。
  - `位置 (Location)`：左对齐，次级灰色文本，显示文件所在的文件夹，超出宽度尾部自动截断。
  - `大小 (Size)`：左对齐，等宽数字字体（`tabular-nums`），格式化为 `B / KB / MB / GB`，与表头“大小”统一左对齐。文件显示自身逻辑大小；文件夹显示索引内全部后代文件的逻辑大小之和，随 USN 变更实时维护，并参与同一列的排序与 `size:` 过滤。junction 不跟随，排除项不计入。
  - `修改时间 (Date Modified)`：左对齐，等宽数字字体，格式化为 `YYYY.MM.DD HH:mm`，按本机时区显示。
- **回收站视图的列语义**：同一张表在回收站位置下把位置列命名为“原位置”、日期列命名为“删除日期”；排序、列宽与拖拽行为不变。表头和无障碍名称都必须反映这个语义差异，不得沿用“修改日期”。

### 1.6 结果区状态规范（空态与索引模式）
- **启动即“所有文件”**：窗口打开后先显示表头；普通首屏查询目标 **≤180ms**，直接呈现结果行；索引在重建或 USN 追赶时，侧栏索引状态行显示对应卷的状态。
- 系统不设“请输入关键词”等中间占位界面，空查询直接呈现全量文件列表。
- **淡灰遮罩与过渡动画**：表格（包含表头）在数据加载完成前统一以 `tokens.muted` 为全域底色遮罩，数据就绪后由该遮罩在 150ms 内淡出揭晓。遮罩只对应正在进行的请求：空态与离线/错误横幅始终可见，其恢复操作不被遮罩覆盖。
- **窗口 resize 遮罩**：拖拽调整窗口尺寸期间，右侧主区域的内容面板以 `tokens.muted` 实体遮罩覆盖，标题栏、侧边栏、搜索带与底栏保持可见；尺寸停止变化、内容重排完成后，遮罩在 150ms 内溶解。

- 索引仍在扫描/追赶时，已有结果继续显示并随状态轮询增量刷新；后台刷新不得清空已显示的行；结果呈现后底栏加载图标随即消失，后台追赶不占用它。
- **空态只表达所属位置的真实状态**：表格查询无匹配（“没有匹配的文件或文件夹，尝试其他关键词或路径”）或索引确实为空（“索引为空，确认后台服务已完成扫描”）；回收站空态与过滤无匹配各自表达，不复用索引为空。服务问题由单行离线态表达。
- 所有模块的状态区共用同一版式：居中 32px 语义图标 + 单行 14px 标题 + 与标题同行的可选 24px 语义 icon 动作（tooltip 与无障碍名称承载完整文案）；标题用等宽侧翼保持水平居中。影响与恢复说明并入标题句，不设独立说明段，也不允许标题与说明分为两行。
- 空态与警告态用中性或警示图标色，错误态用危险色，颜色只落在图标上。瞬态操作结果（删除失败、清空失败）用 toast，状态区不重复表达同一事实。
- **内存位置空态**：“回收站为空”，说明删除的项目会先到这里并可还原或永久删除。过滤无匹配时显示“回收站中没有匹配的项目”，清空过滤由搜索框右侧的清除按钮完成；判断是否为空必须基于全量列表。回收站不依赖索引服务：服务停止时仍显示列表或空态。
- **索引状态与操作收敛在“索引”菜单**：底栏不承载索引模式或卷状态，也不重复索引开关；当属性过滤查询因扩展属性索引关闭而降级时，底栏结果摘要区显示一次警示提示，索引本身的状态与开关仍只在“索引”菜单。侧栏在“位置”列表之后用一条紧凑的索引状态行显示非同步卷（离线、重建、追赶或快照模式），全部同步时该行不出现；不恢复驱动器导航行。后台服务是唯一索引来源，不提供冗余的重启服务入口。索引日志、重扫描、内容索引与扩展属性的状态和开关全部归入顶栏“索引”菜单；文件夹源的增删由“索引 > 文件夹源…”管理弹窗承载，侧栏有源时也提供同入口；逐源重扫描同时在“索引 > 重扫描”列出；只有服务问题在服务已安装但未运行时才显示恢复入口。
- **错误态**：服务未安装、未运行、版本不兼容或拒绝当前账户时，索引结果区显示单行离线态；已安装但未运行给出启动入口，只有可能自行恢复的连接问题给出重试入口，其余情况仅展示恢复指引，不放置无效交互控件。

### 1.7 紧凑侧边栏与间距规范
- 侧边栏宽度 `208px`，由顶栏按钮折叠为图标模式或隐藏。
- “位置”区在文件类型行之后提供“回收站”入口；回收站是位置条目，任一文件类型行与回收站不能同时显示为选中。
- “位置”之后为“文件夹源”区，仅列出服务登记的文件夹源，不恢复驱动器导航行。每行保持 `208px` 单行：文件夹图标、根路径（尾部截断）与状态词（已同步、追赶中、重建中、离线、快照），当前查询作用域所在行高亮。点击行把当前查询限定到该源并立即替换结果集；再次点击同一行、选择任一文件类型、进入回收站或清空查询都会清除作用域，搜索框文本在源内继续生效。区末“管理文件夹源…”打开管理弹窗，支持输入路径添加、逐源重扫描与移除；没有文件夹源时该区不显示，但“索引 > 文件夹源…”始终可打开同一管理弹窗。
- 重复点击当前已选中的分类或回收站会刷新该视图；刷新时表头保持稳定，仅内容区淡入。
- 菜单行带高度取 26px（组件库自身的物理步长，不随缩放变化），行与行之间由组件自带的 2px 纵向间隙分隔，因此行距为 28px；hover 态与选中态不粘连。

### 1.8 底部状态栏规范（高度 28px）
- **表格视图**：显示当前结果的条目数及所占空间（如 `1,071,710 个项目 120.5 GB`；空结果或字节为 0 时只显示条目数），使用等宽数字，刷新不抖动。空间按“最高命中点算一次”合计：命中的目录计入其递归大小，同时被某个命中祖先覆盖的条目不再重复计入。仅当当前视图尚无可用结果（首屏查询、索引首次填充）时，计数前显示旋转加载图标，结果呈现即消失并就地更新；后台卷追赶不占用底栏图标。
- **回收站视图**：使用同一条计数格式显示当前可见（过滤后）项目数；还原所有项目、永久删除与清空回收站由文件菜单承载，底栏不放置这三个动作；还原、永久删除或清空后计数随重新读取的列表更新。列表不可读时显示“回收站不可用”，不把 0 当成真实计数。
- **共同约束**：不显示索引来源胶囊或各卷同步状态在底栏重复出现。底栏加载图标只表示当前视图正在等待自身数据：表格首屏与回收站列表读取；后台索引追赶不在底栏重复反馈。

### 1.9 顶栏菜单与完整设置项
- **同一行**：顶栏最左侧是 `appicon`，随后是 `Cairn` 品牌词标、后退/前进/侧栏按钮，以及 `文件` / `编辑` / `查看` / `搜索` / `索引` / `工具` / `帮助` 七个菜单；保持单条菜单带。单项互斥选择（排序依据、主题、缩放、语言）以圆点标识当前选中项，多选与布尔开关以勾选标识状态。
- **文件**：打开、重命名、打开所在位置、属性、删除；重命名仅在恰好选中一行时可用。回收站视图下改为打开、还原、还原所有项目、永久删除、清空回收站；普通删除使用项目统一的“删除”确认框，正文说明会移到回收站、之后可还原；永久删除使用同一项目确认框，标题与动作写“永久删除”，清空回收站保留 Windows 原生不可逆操作警告。
- **编辑**：撤销、重做、剪切、粘贴、复制路径、复制名称、全选、清空搜索。全选作用于当前焦点面：结果区选中已加载行，搜索框选中查询文本。
- **查看**：排序、显示列、主题、缩放四个子菜单；排序含名称、路径、大小、修改时间、创建时间与扩展名（创建时间与扩展属性排序列仅在索引表格；回收站隐藏这些项，进入时把不支持的主排序按原方向回退到修改时间并写入排序偏好，回收站内该栏为删除日期）；显示列中“名称”始终锁定勾选且不可取消，其余标准列与扩展属性列自由勾选并即时持久化。侧边栏开关只由标题栏左侧的按钮承载；文件类型只由左侧导航承载，二者都不在“查看”中重复。
- **搜索**：区分大小写、全字、匹配路径、正则、拼音、忽略标点、忽略空白、忽略变音符号，以及排除隐藏项目、排除系统项目。
- **就地过滤**：回收站只支持名称/位置子串与区分大小写，因此整字、匹配路径、正则、拼音、忽略标点、忽略空白、忽略变音符号、排除隐藏项目、排除系统项目在回收站内隐藏；显示列与表头右键菜单也隐藏，列布局保持进入前的状态；创建时间与扩展属性排序隐藏，进入时主排序回退到修改时间（回收站内为删除日期），避免对无索引的本地清单承诺无效能力。
- **索引**：包含“索引日志…”“重扫描”“内容索引”“扩展属性”。“索引日志…”打开只读模态查看器弹窗，展示记录开关、条数与内存占用、刷新按钮以及时间/类型/路径列表；时间与类型在首行、完整路径在次行换行显示，避免 384px 宽度下路径不可读；“重扫描”子菜单提供“重扫描全部位置”与各已索引位置；“内容索引”与“扩展属性”子菜单各承载对应开关与只读状态/占用行，其中内容索引在失败时条件展示“重建内容索引”，有索引内容（包括关闭开关或取消构建后保留的索引文件）或失败时展示“清空内容索引”，Backfilling 期间隐藏（清空请求会排队到整轮之后）；清空动作经一次性确认框。后台服务是唯一索引来源，配置重载保留于 CLI 而不在菜单暴露。
- **工具**：包含“语言”（系统/简中/EN）与“开机自启动”，选择即时生效。
- **帮助**：检查更新、关于 Cairn。内容搜索不使用查询开关，统一用 `content:` 语法。
- **更新入口与关于**：帮助 > 检查更新查询 GitHub Releases 最新稳定版；检查期间帮助菜单保持打开，“检查更新”行改为“正在检查更新”并在右侧显示加载图标，不占用 toast。检查结果（已是最新、有可用更新、失败重试）通过右下角轻量通知卡片（Toast）呈现，不弹出模态对话框阻塞浏览；下载安装中沿用常驻信息 toast。从失败 toast 重试时不重新打开帮助菜单。发现新版本时卡片提供“更新”操作按钮，点击后在应用内下载并校验 SHA-256、提权静默安装并重启 Cairn；检查与下载失败保留带“重试”操作的错误通知卡片。安装未完成时下次启动以通知卡片提示。点击“关于 Cairn”直接在默认浏览器打开项目 GitHub 仓库页面，不弹出 Toast 或版本弹窗。

### 1.12 回收站位置视图
- **入口与状态**：侧栏“位置”区的“回收站”是独立位置；进入后底栏显示当前可见项目数。搜索框占位为“搜索回收站…”，就地匹配名称与原位置（支持区分大小写），命中片段与主表格一样加粗；不发起索引查询；整字/匹配路径/正则、拼音/忽略标点/忽略空白/忽略变音符号、排除隐藏项目、排除系统项目在回收站内隐藏；显示列、表头右键菜单与创建时间/扩展属性排序同样隐藏，主排序回退到删除日期。切换位置分类时离开回收站。
- **数据来源**：项目来自 Windows Shell 回收站命名空间，不经过 Cairn 索引；服务停止时仍可浏览、还原或永久删除。列表按当前表头排序，大数据量沿用表格虚拟化与本地分页。
- **选择**：选择以项目身份而非行号保存；过滤、排序、刷新后仍在列表中的项目保持选中，过滤暂时隐藏的项目在清空过滤后恢复选中。深页选择不因只加载首页而丢失。`Ctrl+A` 选择所有已加载行，最多 1,000 项；选中项跨超过 8 个文件夹时，“打开所在文件夹”不批量打开，并提示缩小选择范围。
- **操作**：`Enter` 从回收站负载打开；右键菜单提供打开、还原、复制原位置、复制文件名、全选、永久删除；文件菜单提供还原所有项目、永久删除与清空回收站（Windows 原生确认）。还原成功后项目回到原位置并从列表消失；原目录不存在时由应用重建。
- **确认策略**：普通删除使用项目统一确认框，动作名统一为“删除”，正文说明会移到回收站、之后可还原；永久删除使用与普通删除相同的项目确认框，标题与动作写“永久删除”，正文说明不可还原；清空回收站保留 Windows 原生警告。回收站内的删除是永久操作，不与普通删除共用“删除”。
- **失败反馈**：取消项目确认框或原生警告不是失败，不显示 toast；真实失败只显示一条项目自有视觉语言的 toast，列出 shell 实际未能处理的项（最多 3 个，其余写“还有 N 个项目”）和本地化原因，原始 HRESULT 只进入日志。列表本身读取失败时进入内联“无法读取回收站 + 重试”状态并禁用项目操作，不用旧行冒充最新状态。
- **列语义**：位置列显示“原位置”，日期列显示“删除日期”（按本机时区显示）；两者都参与排序，查看菜单的排序子菜单使用同一组名称。
- **空态**：回收站为空时说明删除的项目会先到这里；过滤无匹配时说明“没有匹配的项目”，清空由搜索框的清除按钮完成，不误报为空回收站。空态和页面其它空态共用同一套图标、间距和字体。

### 1.13 瞬时状态（toast）
- 使用应用自有表面，不直接暴露组件库默认通知样式：`muted` + 1px `border` + 3px 圆角、固定 336px 宽度（随缩放）、单行内容约 77px 的紧凑最小高度、12px 内边距、16px 语义图标、`text_sm` 标题与 12.25px 说明，说明行高 1.5，长文案自然增高，与表格和侧栏共用同一套 `ShellTokens`。恢复动作使用 24px 语义 icon，与说明同行并紧邻说明末尾，tooltip 与无障碍名称写完整文案。
- 信息类 toast 6 秒后自动消失；带操作按钮的信息类（可用更新、安装取消后的重试）与下载安装进度 toast 持续到用户处理或关闭，避免操作入口在读清前消失；错误类持续到用户关闭或按 `Esc`，因为错误承载操作结果。关闭按钮始终可见并有可访问名称；错误类 toast 报告 Alert，信息类报告 status。
- 失败文案列出 shell 实际未能处理的项（最多 3 个，其余写“还有 N 个项目”）和本地化原因；原始 HRESULT 只写日志；取消不产生 toast。

### 1.14 确认弹层
- **动作词**：普通删除的标题与主按钮都写“删除”；“移到回收站”只作为正文里的机制说明，不作为动作名。回收站内的永久删除写“永久删除”，并沿用同一弹层几何与按钮尺寸。
- **模态呈现**：使用主题遮罩（浅色 18%、深色 35%），所有弹层统一为 384px 固定宽度，高度由标题、正文与底部按钮紧凑撑开，不预留固定高度的空带；按约 128px 的紧凑基准定位在窗口中段，正文超过视口时在内容体内滚动；不沿用组件库默认的 448px 宽、顶部 10% 与 6rem 最小高度，避免读成悬浮 toast。
- **按钮与关闭**：底部按钮使用标准中号尺寸，取消在左、动作在右；动作按钮使用 `danger` 语义，取消保持次级；`Esc` 关闭且不执行，确认后才进入 shell 删除流程。
- **动效**：侧边栏折叠/展开使用 200ms 宽度过渡；侧边栏位置、分类与回收站切换视为刷新，表格表头保持稳定，仅内容区在首次内容到达后以 150ms 淡入，不使用入场位移；确认弹层以短距离淡入下滑入场，关闭立即移除；toast 以 140ms 淡入、离场反向淡出，位置不变；tooltip 统一以 150ms、4px 上滑淡入入场。悬停、选中、排序、过滤输入、缩放、窗口缩放与主题切换的状态反馈保持即时，不对高频或直接操控的交互加过渡；减少动态效果时以上过渡直接呈现终态。

## 2. 字体、灰度与对比度约束

- 产品文本按钮统一 500 字重；正文与表格内容 400；选中行与 toast 标题 500。应用内对话框标题使用系统 UI 无衬线字体与 600 字重；状态区标题使用同一无衬线常规字重；仅标题栏 `Cairn` 品牌词标保留 Cormorant SemiBold（中文回退 Noto Serif SC）。安装器与卸载器继续使用衬线标题。
- 灰色分层为 16 档单一无色阶，按 CIE L\* 暗度编号（`GRAY_76` 即 L\* 24），色值见 §1.10。每档至少被一个角色消费；两端画布距纯白/纯黑分别不少于 8 与 20 字节，产品内不出现接近纯色的面值。标题栏、搜索带、侧栏、底栏与安装器页脚共用框架档，表头、未聚焦搜索框和卡片使用内凹档。
- 深色不是浅色的反向推导：16 档中只有 1 档是浅色某档的镜像，深色表面的间距按近黑的感知压缩单独排布（`#14→#1A→#1F` 各 2.5–3.0 L\*）。同一模式内彼此可能相邻的三档——线档、交互档、选区档——间距均 ≥3 L\*，不保留肉眼不可辨的档位。
- 交互填充相对它点亮的表面至少移动 5 个 CIE L\* 单位。深色档位按合成结果选定：`#3A3A3A` 半强度合成后在框架上移动 6.5 L\*，满强度（行、菜单项）移动 12.7 L\*，浅色对应 6.7 与 10.5。线档低一档，借它做 hover 会掉到底线之下。
- 组件库的中性角色全部由本产品色阶供给：`secondary.foreground`、`accent.foreground`、`button.foreground`、`link`、`popover`、`progress_bar`、`scrollbar` 与 `scrollbar_thumb`，避免上游默认值带来的对比度失衡与深色倒挂。彩色状态角色（danger、warning、info、success、chart）保留组件库。
- 主应用搜索框与安装器路径框的静止边界使用 `control_stroke`，聚焦边界使用 `ring`，均保持 ≥3:1（WCAG 1.4.11）；错误态使用 `danger`。安装器路径框使用同一边界层级。
- 全应用 `1px` 边框、`3px` 圆角；安装器进度轨使用 `0.5px` 边框与 `2px` 圆角，分节图标使用 `1.0px` 光学补偿；应用状态图标使用 `1.5px` 光学补偿；标题栏 32px PNG 按 `20px` 绘制。
- 用户界面不渲染原始 URL、物理路径、内部 token、调试枚举、命令行或开发日志；调试信息只进入开发者控制台/内部日志。
- 视觉改动必须捕获当前窗口的新截图；历史截图不得作为最新验收证据。
